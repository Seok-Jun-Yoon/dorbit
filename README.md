# Music EPK — Landing Page Demo

A landing page template built as a portfolio piece: an electronic press kit (EPK) for a band or musical artist, in a contemporary white-and-silver aesthetic aimed at both younger and adult audiences — bio, discography, tour dates, press quotes, and a photo gallery.

**Live demo:** https://pagonzalezmald.github.io/landing-music-epk-demo/

Built by [Pablo Gonzalez](https://github.com/pagonzalezmald) — more examples in [pg_portfolio](https://github.com/pagonzalezmald/pg_portfolio).

## Stack

Vanilla HTML, CSS, and JavaScript — no build step, designed to deploy directly to GitHub Pages.

## Note

This is a demo/template. "Greyfield" is a fictional band; it does not exist. Tracks, tour dates, press quotes, and contact details are illustrative only.
